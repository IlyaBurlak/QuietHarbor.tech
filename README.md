# QuietHarbor.tech

Вишлисты для друзей и семьи. Создавайте списки желаний и делитесь ими по ссылке. Друзья могут бронировать подарки втайне от владельца списка.

- Вишлисты с фото, ценами, ссылками на товары и настройками доступа.
- Друзья и календарь дней рождения.
- Тайный Санта с приглашениями и жеребьёвкой.
- Админ-панель для управления аккаунтами и заявками на сброс пароля.

## Локальный запуск

Нужны Node.js 20+ и Docker Compose. Из корня репозитория выполните:

```bash
cp .env.example .env
npm ci
npm run dev
```

Приложение откроется по адресу <http://localhost:5173>. Настройки базы, API и учётной записи администратора задаются в `.env`.

## Запуск на сервере

В пустом каталоге на сервере с Docker запустите установщик:

```bash
docker run --rm -it \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v "$PWD:/config" \
  ghcr.io/ilyaburlak/quietharbor/installer:0.2.0
```

В меню выберите локальный адрес или домен, задайте учётную запись администратора и при необходимости включите резервные копии. Для ручного запуска скопируйте [.env.production.example](.env.production.example) в `.env.production`, задайте домен, `CLIENT_URL`, пароль PostgreSQL и `SESSION_SECRET`, затем выполните `npm run prod:up`. Управление копиями и восстановление описаны в [инструкции по резервному копированию](deploy/README.md).
